# C++ DSA Pattern Drills (10 Problem Sprint)

## Overview

This repository contains a focused set of 10 foundational Data Structures and Algorithm problems solved in C++. The goal of this sprint is not just problem-solving, but building strong pattern recognition, coding clarity, and engineering discipline.

Each problem is implemented with a focus on understanding core concepts like arrays, strings, hashing, sliding window, two pointers, recursion-style thinking, and functional programming patterns using callbacks.

---

## Objective

- Strengthen core problem-solving fundamentals in C++
- Build a strong understanding of common DSA patterns
- Practice writing clean, modular functions
- Develop confidence in translating logic into code
- Prepare for real-world coding interviews and backend engineering tasks

---

## Topics Covered

### Phase 1: Core Foundations
- Arrays
- Strings
- Hashing (unordered_map, unordered_set)
- Basic function design

### Phase 2: Pattern Thinking
- Two Pointers
- Sliding Window
- Kadane’s Algorithm (Maximum Subarray)
- Frequency counting techniques

### Phase 3: Functional & Design Thinking
- Custom map implementation
- Callback functions
- Transformation pipelines

---

## Problems Included

1. First non-repeating character in a string  
2. Check an anagram without sorting  
3. Maximum sum of contiguous subarray (Kadane’s Algorithm)  
4. Character frequency count using map  
5. Remove duplicates from a sorted array  
6. Rotate the array by k steps  
7. Palindrome number check (without string conversion)  
8. Intersection of two arrays (no duplicates in result)  
9. Longest substring without repeating characters  
10. Custom implementation of map() using callback functions  

---

## Key Learnings

- How to identify and apply DSA patterns
- Difference between brute force and optimized solutions
- Importance of frequency maps and sets in solving problems
- Sliding window technique for substring/subarray problems
- Functional programming concepts in C++ (callbacks)
- Writing reusable and modular code functions

To transition from problem-solving practice → real-world software engineering capability by combining DSA, backend systems, and AI tools.
