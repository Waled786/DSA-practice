# Assignment – 2D Arrays & Matrix Operations

## Overview
This assignment introduced 2D arrays and matrix-based problem solving, including transformations and property checks.

## Topics Covered
- 2D arrays (matrices)
- matrix input/output
- transpose of a matrix
- diagonal matrix check
- identity matrix check
- symmetry check

## Key Learnings
- Row and column-based indexing
- Understanding matrix transformations
- Relationship between indices (i, j)
- Mathematical properties of matrices

## Outcome
Strengthened understanding of structured data in two dimensions and logical matrix analysis.
