# Assignment – Conditional Logic & Problem Solving

## Overview
This assignment focused on decision-making in C++ using conditional statements. It strengthened logical thinking through problems requiring multiple conditions and rule-based evaluation.

## Topics Covered
- if-else statements
- nested conditions
- logical operators (&&, ||, !)
- rule-based validation problems

## Key Learnings
- Breaking problems into logical conditions
- Handling multiple constraints in a single program
- Building decision trees in code
- Strengthening problem interpretation skills

## Outcome
Improved ability to translate real-world conditions into structured programming logic using conditional statements.
