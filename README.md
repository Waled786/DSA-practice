# Assignment 3 – Arrays & Data Handling

## Overview
This assignment introduced arrays and focused on storing and processing multiple values efficiently. The problems emphasized iteration over datasets.

## Topics Covered
- array traversal
- summation and filtering
- max/min value identification
- basic data aggregation

## Key Learnings
- Storing multiple values in a structured format
- Looping through arrays effectively
- Performing calculations on datasets
- Identifying patterns in numerical data

## Outcome
Built a strong understanding of array manipulation and introduced structured data processing in C++.
